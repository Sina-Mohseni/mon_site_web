# Anim'Connect - Carnet numérique de l'animateur

Site web 100% front-end pour les animateurs en accueil de loisirs (groupes PS à CM2).

## 🚀 Démarrage rapide

### Installation
```bash
npm install
```

### Lancement en développement
```bash
npm run dev
```
Le site sera accessible à : **http://localhost:3000**

## 🐛 DÉPANNAGE : PAGE BLANCHE

Si vous voyez une page blanche, suivez ces étapes :

### 1. Rechargement forcé du navigateur
- **Windows/Linux** : Ctrl + Shift + R ou Ctrl + F5
- **Mac** : Cmd + Shift + R

### 2. Videz le cache du navigateur
- **Chrome** : Ctrl + Shift + Delete → Images et fichiers en cache → Effacer
- **Firefox** : Ctrl + Shift + Delete → Cache → OK

### 3. Vérifiez la console du navigateur
1. Appuyez sur F12
2. Allez dans "Console"
3. Partagez les messages d'erreur (en rouge)

### 4. Redémarrez le serveur
```bash
# Arrêtez le serveur (Ctrl+C dans le terminal)
# Puis relancez :
npm run dev
```

### 5. Essayez le build de production
```bash
npm run build
npm run preview
```
Allez sur http://localhost:4173

## 🛠️ Commandes
